# MemberSplit · Strada Halloween Edition

一个**单文件、可离线运行**的随机分组工具，为 Strada 万圣节活动定制的 Halloween Edition。读取 Excel / CSV 名单，按可复现的种子把成员分到 **Team A / Team F**，自动满足角色约束并平衡人数，带抽取动画，支持导出 Excel / CSV。

打开 [MemberSplit.html](MemberSplit.html) 即可使用——无需安装、无需联网、无需服务器。

---

## 快速开始

1. 用 Chrome / Edge 打开 `MemberSplit.html`。
2. 点击「选择 Excel 文件」，或直接「载入示例名单」体验。
3. 确认角色：**至少 2 名 Team Lead**、**至少 2 名 SME**。角色不完整时无法开始。
4. 按需修改队伍名称、种子和动画速率。
5. 点击「开始分组」。动画结束后可导出 Excel、CSV，或复制为表格文本。

单文件说明：界面、应用逻辑和 Excel 解析引擎（SheetJS）全部内嵌在 HTML 中。打开后不会发起任何网络请求，可以断网使用，也可以拷贝到其他电脑直接打开。

## 读取 Excel

支持 `.xlsx`、`.xls`、`.xlsm`、`.xlsb`、`.csv`。

左侧「数据源」可配置：

| 配置 | 说明 |
| --- | --- |
| 工作表 | 工作簿中的任意工作表 |
| 起始行 | 名单数据的实际起始行（从 1 开始计数） |
| 姓名列 | A / B / C…，下拉中会显示表头与首个样例 |
| 角色列 | 可选；用于自动识别 Team Lead / SME |

自动识别会寻找常见中英文表头（`姓名`、`成员姓名`、`Name`、`Full Name` 等）以及角色表头（`角色`、`身份`、`Role` 等），并跳过标题行。识别不准确时，直接在左侧手动选择即可。

角色值的识别规则：

- **Team Lead**：`Team Lead`、`Lead`、`TL`、`队长`、`组长`、`领队`、`负责人`
- **SME**：`SME`、`Subject Matter Expert`、`专家`
- **Member**：`Member`、`成员`、`组员`、`员工`，以及其他未识别的值

没有角色列也能用：在「角色配置」中为成员逐个选择角色即可。角色下拉会实时校验，只有至少 2 Lead + 至少 2 SME 时才能开始。

限制：单表最多读取前 5000 行、64 列；CSV 建议使用 UTF-8 编码。

## 分组规则

- **至少 2 名 Team Lead**：两队按人数尽可能均分，两队 Lead 人数差不超过 **1**（因此每队至少 1 名；Lead 总数为奇数时，多出的一人由种子决定）。
- **至少 2 名 SME**：同样按人数尽可能均分，两队 SME 人数差不超过 **1**（SME 总数为奇数时，多出的一人由种子决定；具体是谁由姓名键决定）。
- **颜色标识**：分组结果、抽取台与左侧角色配置均不显示 Team Lead / SME 的文字标签；金色代表 Team Lead、紫色代表 SME、中性色为普通成员。每队内部仍按 Team Lead → SME → Member 的顺序排列。角色配置中每一行用三个色点切换角色。
- **人数补偿**：按总人数均分，并补偿角色基础人数造成的偏差。最终人数差恒为 **0 或 1**（规则上限为 3）。
- **姓名参与随机**：每个角色池内按 `hash(种子 + 姓名)` 生成稳定键并排序，再按排序结果落位；不再按名单行序洗牌。因此同一批人、相同种子，无论 Excel 行顺序如何，分组结果完全相同。
- **种子**：默认是当天的 `yyMMdd`（如 2026 年 10 月 22 日为 `261022`），可输入任意字符串。留空时使用开始分组时的**毫秒时间戳**，并会在结果区和导出信息中显示实际种子。
- 相同姓名 + 相同角色 + 相同种子 = 完全相同的结果，与名单行顺序无关；改名会改变随机键，从而可能改变结果。队名只影响展示和导出，不参与随机。
- 点击「换一组」会生成新的时间戳种子并重新抽取；「重新分组」沿用当前种子，因此会复现同一结果。

> 完整的算法说明（哈希、角色分配、人数补偿、证明与示例）见 [docs/grouping-algorithm.md](docs/grouping-algorithm.md)。

## 动画

- 逐名抽签：名字滚动 → 锁定 → 进入对应队伍；Team Lead 最后揭晓。
- 动画速率 **0.5× – 4×** 可调，并显示预计时长。
- 抽取中可按 `Esc` 或点击「跳过动画」立即完成。
- 「重播」会按相同结果重新播放动画。

## 导出

- **Excel**：两个工作表——「分组结果」（第一列 Team A 姓名、第二列空白分隔、第三列 Team F 姓名，不显示角色）和「分组信息」（队名、种子、生成时间、来源、列配置、约束与复现说明）。
- **CSV**：与 Excel 相同的并排姓名布局；UTF-8 BOM，直接双击用 Excel 打开中文不乱码。
- **复制**：制表符分隔，同样是「A 队姓名 / 空列 / F 队姓名」，可直接粘贴到 Excel / 飞书 / Notion。
- 导出使用**当前**队名。名单或角色变化后会提示结果已过期，需要重新分组才能导出。

## 隐私

- 所有解析、分组、导出都在本机浏览器中完成。
- 不上传名单，不调用任何远端接口。
- 仅会用 `localStorage` 记住**队名和动画速率**，不保存名单或分组结果。
- 关闭页面即清除当前名单；导出的文件由你自己保管。

## 开发 / 构建

应用本身不需要 Node.js。只有修改源码或运行测试时才需要。

```bash
# 修改 src/app.js 或 src/template.html 后，重新生成 MemberSplit.html
node src/build.mjs

# 重新生成示例名单
node src/make-sample.cjs

# 安装测试依赖（只需一次），然后运行全部测试
npm install
npm test
```

测试使用 `playwright-core` 驱动本机 **Chrome**（`channel: 'chrome'`），不会下载额外浏览器。测试覆盖：

- 种子默认值、留空时间戳、复现性与不同种子的差异性
- 姓名参与随机：同一批人改变名单行顺序（正序 / 倒序 / 交错）后结果一致，改名会改变结果
- Team Lead / SME 均至少 2 名、两队同类角色人数差 ≤ 1、总人数差 ≤ 1（压力测试覆盖 4 至 50 人、2 至 7 名 Lead、2 至 15 名 SME，每种 8 个种子共 56 次抽取）
- `.xlsx` / `.xls` / `.csv` 导入、起始行与列配置、非 A1 起始的偏移表格
- 角色列自动识别、中文角色、无角色列时的手动指定
- 动画跳过、重播、导出 Excel / CSV、剪贴板复制、插入 HTML 的姓名不执行
- 完全离线（无 HTTP(S) 请求）、Chrome 无运行时错误、移动端布局

## 浏览器支持

完整测试套件在 Chrome 上运行通过，并额外在 Edge 中验证了离线加载、分组与导出相关流程。应用使用现代浏览器 API（`dialog`、`Blob` 下载、CSS 自定义属性等），建议使用近两年的 Chrome / Edge / Firefox / Safari。如果浏览器较旧，请升级后再使用。万圣节装饰在窄屏会按需隐藏，以优先保证分组操作的可用性。
